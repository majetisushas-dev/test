1. Prepare your agent

Create and publish a short English test assistant, or use an existing agent.

2. Connect your own model server

Run the voice stack on your computer or server, keep it online, and connect its HTTPS address to this app. Its token stays in server settings.

  1. Clone the repository and install Docker.
  2. Create a private runtime token and start the supplied voice Compose stack.
  3. Set its HTTPS address and matching token in Render.

Required Render settings: VAANI_VOICE_RUNTIME_URL and VAANI_VOICE_RUNTIME_TOKEN.

Model server setup instructions ↗
Not checked yet.

3. Connect a phone provider

Create a LiveKit project with SIP support and an outbound SIP trunk from a carrier such as Telnyx or Plivo. Your carrier supplies an authorized caller ID and paid phone minutes.

Add your LiveKit URL, API key, secret, and outbound trunk ID privately in Render. Enable outbound calling only after a successful audio test.

Phone provider setup instructions ↗
A 15-minute call limit is configured. Phone network charges still apply. No account signup or purchase is performed by this screen.

4. Test the full voice pipeline

Speak or upload an audio sample. Listen to the real model-generated response. This test does not dial a phone.

Record up to 20 seconds, or upload an audio file.

5. Place a real call

After the voice test passes, choose a contact who agreed to receive the call. Review its status and transcript in Calls.
